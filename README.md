# Supermarket Sales Data Analysis

## Project Overview
The Supermarket Sales Data Analysis project focuses on analysing real-world supermarket transaction data to understand sales performance, customer behaviour, product performance, and business trends. The project uses Python and its popular data analysis libraries to explore, clean, process, visualize, and interpret the dataset.

The main purpose of this project is to extract meaningful insights from raw sales data and understand how data analysis can help businesses make better decisions.

## Dataset Description
The project uses a supermarket sales dataset containing **1,000 records and 17 columns**. The dataset includes information about invoice IDs, branches, cities, customer types, gender, product lines, unit prices, quantities, total sales, payment methods, gross income, and customer ratings.

The dataset covers transactions from January 2019 to March 2019.

## Tools and Technologies Used
The following tools and libraries were used:
- **Python:** For performing data analysis.
- **Jupyter Notebook:** For writing and executing Python code.
- **Pandas:** For data loading, cleaning, processing, and analysis.
- **NumPy:** For numerical operations.
- **Matplotlib:** For creating graphs and visualizations.
- **Seaborn:** For creating correlation heatmaps.

## Project Activities
The project includes the following activities:
1. Loading the supermarket sales dataset using Pandas.
2. Exploring the dataset using functions such as `head()`, `info()`, `describe()`, and `shape`.
3. Checking for missing values and duplicate records.
4. Converting the Date column into the correct datetime format.
5. Performing Exploratory Data Analysis (EDA).
6. Analysing sales by branch, product line, customer type, gender, and payment method.
7. Creating visualizations to understand sales patterns and trends.
8. Performing correlation analysis to identify relationships between numerical variables.
9. Interpreting the results and preparing final business insights.

## Key Findings
- Branch C generated the highest total sales.
- Food and beverages was the highest revenue-generating product line.
- Member customers contributed more sales than Normal customers.
- Female customers generated higher sales than male customers.
- Cash was the highest revenue-generating payment method.
- January recorded the highest monthly sales during the analysed period.

## Conclusion
This project provided practical experience in real-world data analysis using Python. It helped develop skills in data cleaning, preprocessing, exploratory data analysis, data visualization, and business insight generation.

The project demonstrates how raw business data can be converted into meaningful information that supports better business understanding and decision-making.
